# AI Working Notes

Use this directory for temporary handoff notes, investigation summaries, or implementation plans that should not become durable project truth.

Promote lasting findings into the canonical docs and prune temporary notes when they are superseded.

Good candidates for this directory:

- A short handoff note for a partially completed investigation.
- A temporary implementation plan that should not become a roadmap.
- A debugging transcript summary that explains what was tried and what remains unknown.

Poor candidates for this directory:

- Stable architecture or runtime behavior; put that in `docs/01-repo-overview.md`.
- Current risks, validation status, or known gaps; put that in `docs/02-current-status.md`.
- Next concrete tasks; put those in `docs/04-next-steps.md`.
- Agent guardrails that should apply before reading project docs; keep those in `AGENTS.md`.
